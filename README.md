# Crumb & Chai

Playful, animated café website for Crumb & Chai, Hauz Khas, New Delhi.

Built with Next.js 14, Tailwind CSS, and Framer Motion.

## Features
- Responsive design with smooth animations
- Menu with filters
- Reservation form
- Gallery lightbox
- WhatsApp integration
- Custom cursor & sticky header
